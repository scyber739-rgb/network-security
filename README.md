## Lab safety

- Use only a FortiGate VM/appliance and networks you own or are explicitly authorized to test.
- Keep the lab isolated from your home or production network unless you understand and intentionally configure the routing.
- Do not publish passwords, license files, serial numbers, public IPs, MAC addresses, VPN secrets, or unredacted screenshots.
- Record the FortiOS version and the exact lab topology used. Menu names and CLI syntax can vary by FortiOS version.

## Learning workflow

Each day follows: concept → guided configuration → verification → troubleshooting → sanitized screenshots → GitHub notes → interview questions.

## Progress

Week 1 is the active learning track. Mark a task complete only after performing and verifying it in the lab.
