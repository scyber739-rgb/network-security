## Lab safety and privacy

- Perform tests only on networks and devices you own or are authorized to assess.
- Redact public IP addresses, private network details where appropriate, MAC addresses, Wi-Fi SSIDs, usernames, and other identifying information before publishing screenshots.
- Record observed results accurately; a successful gateway ping does not prove that every network segment or internet service is healthy.
